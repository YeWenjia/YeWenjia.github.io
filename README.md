Personal page: https://yewenjia.github.io

The site is plain HTML and CSS, so there is no build step:

- `index.html` holds all the content. To add a paper, copy one `<li class="pub">` block in the Publications section and edit it.
- `style.css` holds the styles (light and dark mode).
- Paper PDFs go in `papers/`, images in `pic/`.
